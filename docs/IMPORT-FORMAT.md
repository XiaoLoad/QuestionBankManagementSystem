# 题库导入 JSON 格式规范

本文档用于指导 AI 将拍照/扫描的题目转换为标准 JSON 格式，以便导入题库管理系统。

---

## 一、整体结构

JSON 文件为一个**数组**，每个元素是一道题目对象：

```json
[
  { "type": "...", "content": "...", "options": [...], "answers": [...], "category": "..." },
  { "type": "...", "content": "...", "options": [...], "answers": [...], "category": "..." }
]
```

---

## 二、字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | string | ✅ | 题型，只能是下列 5 种之一 |
| `content` | string | ✅ | 题目正文（题干） |
| `options` | string[] \| null | 视题型 | 选项列表，仅单选题和多选题需要 |
| `answers` | string[] \| null | ✅ | 正确答案，**必须是数组格式** |
| `category` | string | ❌ | 分类名称，不填则为 `"默认"` |

---

## 三、5 种题型详解

### 1. 单选题

- `type`: `"单选题"`
- `options`: **必填**，字符串数组，列出所有选项
- `answers`: **必填**，数组中只放**一个**正确选项的**完整文本**

```json
{
  "type": "单选题",
  "content": "教育的基本功能不包括以下哪项？",
  "options": ["经济功能", "政治功能", "教育职能", "文化功能"],
  "answers": ["教育职能"],
  "category": "教育学"
}
```

**要点：**

- `answers` 里存的是选项的**文字内容**，不是字母（不要写 `["C"]`，要写 `["教育职能"]`）
- 系统会自动去除答案中的字母前缀（如 `"C.教育职能"` 会自动变成 `"教育职能"`）

---

### 2. 多选题

- `type`: `"多选题"`
- `options`: **必填**，字符串数组
- `answers`: **必填**，数组中放**多个**正确选项的完整文本

```json
{
  "type": "多选题",
  "content": "以下属于教育的社会功能的有（）",
  "options": ["经济功能", "政治功能", "个体发展功能", "文化功能"],
  "answers": ["经济功能", "政治功能", "文化功能"],
  "category": "教育学"
}
```

**要点：**

- `answers` 包含所有正确选项，顺序无关
- 即使题目只有两个正确选项，也要用数组格式

---

### 3. 判断题

- `type`: `"判断题"`
- `options`: `null`（判断题没有选项）
- `answers`: **必填**，只能是 `["对"]` 或 `["错"]`

```json
{
  "type": "判断题",
  "content": "教育的本质是一种有目的的培养人的社会活动。",
  "options": null,
  "answers": ["对"],
  "category": "教育学"
}
```

**要点：**

- 不要写 `["正确"]`、`["错误"]`、`["√"]`、`["×"]`
- 只用 `["对"]` 或 `["错"]`

---

### 4. 填空题

- `type`: `"填空题"`
- `options`: `null`
- `answers`: **必填**，数组格式，每个空的答案作为一个字符串元素

```json
{
  "type": "填空题",
  "content": "教育的基本要素包括____、____和____。",
  "options": null,
  "answers": ["教育者", "受教育者", "教育影响"],
  "category": "教育学"
}
```

**多个空的情况：**

- 题目中有几个 `____`，`answers` 数组就应有几个元素
- 答案顺序对应空的顺序

```json
{
  "type": "填空题",
  "content": "世界上面积最大的国家是____，人口最多的国家是____。",
  "options": null,
  "answers": ["俄罗斯", "中国"],
  "category": "地理"
}
```

**只有一个空：**

```json
{
  "type": "填空题",
  "content": "光在真空中的传播速度约为____m/s。",
  "options": null,
  "answers": ["3×10^8"],
  "category": "物理"
}
```

---

### 5. 简答题

- `type`: `"简答题"`
- `options`: `null`
- `answers`: **必填**，数组格式，通常只有一个元素，即参考答案全文

```json
{
  "type": "简答题",
  "content": "简述教育的个体功能和社会功能的区别。",
  "options": null,
  "answers": ["教育的个体功能是指教育对个体发展的影响和作用，包括个体社会化和个体个性化。教育的社会功能是指教育对社会发展的影响和作用，包括经济功能、政治功能、文化功能和人口功能。"],
  "category": "教育学"
}
```

---

## 四、分类（category）

- 分类用于对题目进行分组管理，如按学科、章节、课程分类
- 不填写时默认为 `"默认"`
- 建议使用有意义的分类名，如书名、章节名

```json
{ "category": "教育学" }
{ "category": "大学英语·第三单元" }
{ "category": "高等数学·微积分" }
```

---

## 五、图片处理

如果题目中包含图片（如公式图、示意图）：

- 将图片上传到图床，获取图片 URL
- 在 `content` 中用 Markdown 图片语法嵌入：`![图片描述](https://example.com/image.jpg)`
- 或者直接将图片 URL 单独放在 `images` 字段中（如果 AI 能提取的话）

```json
{
  "type": "单选题",
  "content": "如图所示，函数 f(x) 的图像在 x=0 处的导数是（）\n![函数图像](https://example.com/graph.png)",
  "options": ["正数", "负数", "零", "不存在"],
  "answers": ["正数"],
  "category": "高等数学"
}
```

## 七、常见错误提醒

### ❌ 错误写法

```json
{
  "type": "单选",
  "content": "题目内容",
  "options": ["A选项", "B选项"],
  "answers": ["A"],
  "category": "默认"
}
```

### ✅ 正确写法

```json
{
  "type": "单选题",
  "content": "题目内容",
  "options": ["A选项", "B选项"],
  "answers": ["A选项"],
  "category": "默认"
}
```

**常见错误列表：**

| 错误 | 正确 |
|------|------|
| `"type": "单选"` | `"type": "单选题"` |
| `"type": "多选"` | `"type": "多选题"` |
| `"type": "判断"` | `"type": "判断题"` |
| `"type": "填空"` | `"type": "填空题"` |
| `"type": "简答"` | `"type": "简答题"` |
| `"answers": ["A"]` | `"answers": ["具体选项文字"]` |
| `"answers": ["正确"]` | `"answers": ["对"]` |
| `"answers": "答案"` | `"answers": ["答案"]`（必须是数组） |
| `"options": ["A.选项"]` | `"options": ["选项"]`（不要带字母前缀） |

## 八、给 AI 的处理指令

当用户提供题目图片或文字时，请按以下步骤处理：

1. **识别题型**：根据题目特征判断是单选题、多选题、判断题、填空题还是简答题
2. **提取题干**：完整提取题目正文，保留标点符号
3. **提取选项**（如有）：逐个提取选项文字，去掉 `A.` `B.` `C.` `D.` 等字母前缀
4. **确定答案**：
   - 单选题：将正确选项的完整文字放入 `answers`
   - 多选题：将所有正确选项的完整文字放入 `answers`
   - 判断题：`["对"]` 或 `["错"]`
   - 填空题：按顺序放入每个空的答案
   - 简答题：放入参考答案全文
5. **设置分类**：根据用户指定的分类填写，未指定则留空或写 `"默认"`
6. **输出 JSON**：输出合法的 JSON 数组格式

### 输出格式要求

- 输出纯 JSON，不要包含 markdown 代码块标记
- 确保 JSON 格式合法，可直接导入系统
- 字符串中的特殊字符（如引号、换行）需要正确转义
- 一道题也要放在数组中：`[{ ... }]`
